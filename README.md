# Budget Splitter

A modern, client-side web application for splitting expenses among friends and groups. Built with **React** and styled with **Tailwind CSS**.

## Features

-   **Dashboard View**: Manage multiple budget forms in a clean, card-based interface.
-   **Expense Tracking**: Add, edit, and remove expenses for each budget.
-   **Split Calculation**: Automatically calculates the total cost and split amount per person.
-   **Responsive Design**: Fully responsive UI that works on desktop and mobile.
-   **Client-Side Persistence**: Works entirely in the browser.

## Tech Stack

-   React 18
-   Vite
-   Tailwind CSS
-   ESLint

## Getting Started

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
4.  Build for production:
    ```bash
    npm run build
    ```
